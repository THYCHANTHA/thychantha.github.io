Adult Census Income Analysis

EDA, preprocessing, classification and unsupervised analysis (PCA, clustering) of the UCI Adult Census Income dataset, written up as a LaTeX report.

View on GitHub

Problem

Understand the structure and quality of the data, find patterns between demographics and income, and build a classifier.

Overview

ITC course project (Exploratory Data Analysis and Unsupervised Learning) on the 1994 US Census income data, predicting whether annual income exceeds $50,000.

Methodology

  • Handling missing values, duplicates, outliers and skewed distributions
  • Classification models for income
  • PCA and clustering for unsupervised exploration
  • Full write-up in LaTeX

Technologies

  • Python
  • Pandas
  • Scikit-learn
  • PCA
  • Clustering
  • LaTeX

Results

  • Class imbalance: 78% earn $50K or less, 22% more
  • Final Gradient Boosting classifier reached 87.80% accuracy (about 85% for the baseline), as reported in the repository README
