Cambodia Agricultural Data Warehouse

A tested PostgreSQL star schema (Bronze, Silver, Gold) that integrates public crop, climate and development data for Cambodia, built with dbt and Prefect and explored in Streamlit.

Open full page View on GitHub

Problem

Public sources arrive in different formats, units, geographic levels and time steps. The question was whether they can be integrated into one consistent, tested structure without mixing incompatible grains.

Overview

Research prototype (v0.1.0) that integrates FAOSTAT national crop statistics, World Bank indicators and CHIRPS rainfall aggregated to provinces into one documented warehouse. It is the data-infrastructure foundation for later agricultural forecasting work.

Methodology

  • Bronze, Silver and Gold layers with explicit grains for every fact table
  • Pipeline orchestration with Prefect and transformations and tests in dbt
  • Independent verification script for the Gold layer
  • Streamlit dashboard over the warehouse

Key features

  • Facts: crop production (country x year x crop), indicators (country x year), climate (province x month)
  • Dimensions for date, geography (country and 25 provinces), crop, indicator and data source

Technologies

  • PostgreSQL
  • dbt
  • Prefect
  • Python
  • Streamlit
  • Data Warehouse

Results

  • Gold tables: 2,658 crop-production rows, 528 indicator rows, 25 climate rows
  • dbt test: 42 of 42 passed; independent Gold verification: 31 of 31 passed
  • Database integration and dashboard tests: 13 passed; unit tests: 32 passed

Scope is deliberate: only national crop statistics, no provincial crop statistics, and only one month of CHIRPS rainfall (July 2023) is loaded. It is a research prototype, not an official statistical product.
