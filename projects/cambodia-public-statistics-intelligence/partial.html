Cambodia Public Statistics Intelligence

A reproducible World Bank pipeline (DuckDB) and Streamlit observatory comparing Cambodia with ASEAN across 25 development indicators, with missing data shown rather than filled.

Open full page View on GitHub

Problem

Public development statistics are spread across portals with different structures, metadata and gaps. The aim was to improve access to information on Cambodia's socioeconomic development and its position within Southeast Asia.

Overview

Independent educational and research project that integrates 25 World Bank World Development Indicators for Cambodia, the ten other ASEAN members and Czechia (as an external benchmark) into a DuckDB store.

Methodology

  • Reproducible ingestion from the World Bank Indicators API v2 (51 API calls, 19,800 rows)
  • Standardised country and indicator metadata
  • Descriptive statistics, trend analysis, exploratory correlation and outlier review flags
  • Same-year country comparison and a data-quality dashboard

Key features

  • Streamlit observatory
  • Completeness and data-quality dashboard
  • Licence audit with per-indicator attribution; no data redistributed in the repository

Technologies

  • Python
  • DuckDB
  • Streamlit
  • World Bank API
  • Data Quality

Results

  • 30.2% of the 19,800 country-indicator-year cells are missing in the source; the app shows them instead of filling them

Research prototype v0.1.0, not an official product of the Government of Cambodia, the National Institute of Statistics, the World Bank or ASEAN.
