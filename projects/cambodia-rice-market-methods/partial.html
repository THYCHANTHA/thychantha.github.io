Cambodia Rice Market Methods

Open methods and code for analysing rice export statistics: ingestion, validation, reconciliation, market analytics and rolling-origin forecast evaluation.

Open full page View on GitHub

Problem

Trade statistics from different providers disagree and arrive in awkward formats. The project builds the checking, reconciliation and evaluation steps that make an analysis trustworthy before any model is fitted.

Overview

A methods-and-code release rather than a publication of findings. The dashboard runs on clearly labelled synthetic demonstration data, or on data the user loads under each provider's terms.

Methodology

  • Strict parsers (units, separators, blanks kept as missing) feeding a DuckDB warehouse with explicit grains and constraints
  • Validation: duplicates, gaps, negative values, annual totals, partner sums and mirror statistics
  • Analytics: growth rates, seasonal index, destination shares, HHI and export unit value
  • Expanding-window backtests of naive, seasonal naive, mean, ETS, ARIMA and SARIMA baselines with a paired bootstrap

Key features

  • 7-page Streamlit dashboard with an honest empty state
  • No forward forecasts and no cached provider data

Technologies

  • Python
  • DuckDB
  • Streamlit
  • ARIMA / SARIMA
  • Time-Series Forecasting

Results

Research pre-release. It contains no real export figures or results; the author's own results are unpublished pending clarification from the data providers.
