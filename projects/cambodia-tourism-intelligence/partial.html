Cambodia Tourism Intelligence & Demand Analytics

A data pipeline, validation framework and 8-page Streamlit dashboard for Cambodia's official tourism statistics, with forecasts held to a seasonal-naive baseline.

Open full page View on GitHub

Problem

Tourism statistics are published as monthly series, annual breakdowns and PDF reports with different definitions, so summing or comparing them without validation produces wrong totals.

Overview

Tourism is a main source of foreign exchange and employment, but official statistics come in several formats and levels of aggregation. This project builds the infrastructure to analyse them correctly and reproducibly.

Methodology

  • Strict ingestion of manually supplied official files with SHA-256 checksums
  • Validation: missing months, duplicate keys, negative values and reconciliation against reported totals
  • Parquet and DuckDB warehouse that never sums total rows with detail rows
  • Forecast backtests; a model is only reported if it beats seasonal naive

Key features

  • 8-page interactive dashboard that states clearly when data are missing

Technologies

  • Python
  • DuckDB
  • Parquet
  • Streamlit
  • Time-Series Forecasting
  • Data Quality

Results

In progress. The software is built and tested, but no Cambodian tourism data has been analysed yet and the repository contains no findings or forecasts; data will be loaded once the sources' licensing terms are confirmed.
