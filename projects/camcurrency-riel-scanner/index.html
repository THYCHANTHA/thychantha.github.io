CamCurrency: Khmer Riel Scanner & Calculator

Detects, classifies and sums Cambodian riel banknotes from images or a webcam, from data collection to a containerised deployment. ITC Group 5 team project, led by me.

View on GitHub

Problem

Counting mixed banknotes by hand is slow and error-prone. The system recognises each note and adds up the total automatically.

Overview

A full-stack application covering the whole pipeline from raw data collection and model training to a containerised deployment behind Nginx on a DigitalOcean droplet.

Methodology

  • YOLOv8 custom-trained to identify 7 classes of riel notes (100 to 50,000 riel)
  • FastAPI backend, React with Tailwind frontend (dark and light mode), PostgreSQL detection history
  • Docker Compose orchestration; Nginx reverse proxy on a DigitalOcean droplet

Key features

  • Real-time calculator that sums detected notes
  • Live webcam integration

Technologies

  • YOLOv8
  • FastAPI
  • React
  • PostgreSQL
  • Docker
  • Nginx

Results

  • The repository README reports a model trained on 1,000+ images with 94% mAP (as stated by the team; not re-verified here)

My role as team leader: system architecture, YOLOv8 model training, FastAPI backend and DevOps (Docker and VPS deployment).
