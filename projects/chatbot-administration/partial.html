Chatbot Administration

Designed and proposed a secure, role-based chatbot for department administration serving 400+ users.

Open full page View PDF

Problem

Departments often answer repeated questions about schedules, scores, events, and procedures. The goal was to reduce repetitive support work while protecting data access and system security.

Overview

This project proposes a secure, role-based chatbot for department administration, integrating LangChain, OpenAI GPT-3.5, PostgreSQL, and Streamlit to handle queries, schedules, scores, and events for 400+ users with enhanced security.

Methodology

  • Role-based access for students and teachers
  • LangChain-powered conversational AI
  • Schedule, score, and event queries
  • PostgreSQL-backed data access
  • Streamlit interface
  • Security-focused architecture

Technologies

  • AI
  • LangChain
  • Database Management
  • Security

Results

Defined a cost-effective, secure chatbot system capable of streamlining department communication for 400+ users.
