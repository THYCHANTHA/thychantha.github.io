CyberGuard

An intelligent AI chatbot for real-time scam and phishing detection, integrated with Telegram and web platforms.

Open full page View PDF

Problem

Online users are frequently exposed to scams and harmful messages that are difficult to verify quickly. The goal was to improve awareness and support safer digital decisions through AI-assisted detection.

Overview

CyberGuard is an intelligent AI chatbot for real-time scam and phishing detection, integrated with Telegram and web platforms, including a reporting system to combat cybercrimes like spam, fake ads, and phishing in Cambodia.

Methodology

  • Real-time scam and phishing detection
  • Telegram bot integration
  • Web platform integration
  • User reporting system
  • Cambodia-focused cybercrime use cases

Technologies

  • AI Detection
  • Cybersecurity
  • Chatbot
  • Reporting System

Results

Supports safer online communication in Cambodia by helping users identify risky messages and report scams quickly.
