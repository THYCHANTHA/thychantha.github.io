FinRisk AI: Explainable Credit-Default Prediction

Three models compared on credit-card default (UCI Taiwan data) with SHAP explanations, a fairness-minded experiment on demographic features and a Streamlit dashboard.

Open full page View on GitHub

Problem

How can machine-learning models predict credit-default risk while staying interpretable, reliable and responsible in how demographic information is treated?

Overview

An educational study using the public UCI Default of Credit Card Clients dataset. It is not a real credit assessment or lending system, and the data are from Taiwan, not Cambodia.

Methodology

  • Logistic Regression, Random Forest and Gradient Boosting on one fixed split
  • Model selection by a pre-declared rule (validation PR-AUC), paired bootstrap for differences
  • SHAP explanations and calibration checks
  • Controlled experiment with and without demographic variables

Technologies

  • Python
  • Scikit-learn
  • SHAP
  • Streamlit
  • Explainable AI

Results

  • Test set of 6,000 clients, default rate 22.1%
  • ROC-AUC 0.780 for Random Forest (selected) and Gradient Boosting, 0.743 for Logistic Regression
  • Random Forest and Gradient Boosting are statistically tied; the model is driven mainly by repayment history

Educational demonstration: not production financial advice.
