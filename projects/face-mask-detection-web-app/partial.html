Face Mask Detection Web App (Docker)

A containerised web app that detects face masks in uploaded images or a live webcam feed: YOLOv8 served by FastAPI, a React interface and PostgreSQL detection history.

Open full page View on GitHub

Problem

A trained model is only useful when people can use it. The goal was to serve it through an API and interface, store a history and make it run the same way on any machine.

Overview

ITC team project that packages a trained YOLOv8 detector behind a REST API and a browser interface so anyone can upload a photo or point a webcam at a scene.

Methodology

  • YOLOv8 inference behind a FastAPI backend (confidence threshold 0.15)
  • React and Vite frontend drawing boxes, labels and confidence over the image
  • Webcam frames analysed about once a second without being saved
  • PostgreSQL history of detections; Docker Compose for the whole system

Technologies

  • YOLOv8
  • FastAPI
  • React
  • PostgreSQL
  • Docker
