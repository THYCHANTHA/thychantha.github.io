Face Mask Detection

Real-time computer vision system to classify mask compliance (no mask, incorrect mask, correct mask) with a fine-tuned YOLOv8 model, served through a Flask web application.

Open full page View PDF View on GitHub

Problem

Manual monitoring of mask compliance is slow and inconsistent in crowded spaces. The goal was to demonstrate how automated visual detection can support safer environments and faster screening.

Overview

This project applies computer vision and deep learning to detect whether people are wearing face masks correctly in images and video streams, supporting public health monitoring and safety compliance checks.

Methodology

  • Real-time mask compliance classification
  • Three-class detection: no mask, incorrect mask, correct mask
  • Face region detection pipeline
  • YOLOv8-based object detection
  • Model evaluation and visualization
  • Deployed as a working application

Technologies

  • Python
  • Data Pre-processing
  • YOLOv8
  • Scikit-learn
  • Visualization

Results

Deployed as a working Flask application for image, video and webcam detection. A later held-out audit of the model (see the Face-Mask YOLOv8 audit project) measured test mAP50 of 0.781 after removing duplicate images, and found the rare incorrect-mask class weak.
