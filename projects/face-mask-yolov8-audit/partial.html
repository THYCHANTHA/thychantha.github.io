Face-Mask YOLOv8: Audit and Held-out Re-evaluation

A critical re-evaluation of my own face-mask model: rebuilding the split, checking for train/test leakage and scoring the recorded weights on unseen images.

Open full page View on GitHub

Problem

The original notebook never scored its test split and quoted an accuracy figure with no source. The question was how reliable the model actually is.

Overview

Takes the earlier course project (a YOLOv8n model in a notebook served by a Flask app) and asks how well the model really performs on images it has never seen, and whether the original evaluation is trustworthy.

Methodology

  • Rebuilt the original data split from the notebook's code and reproduced the best training epoch
  • Duplicate detection with file hashes and a 64-bit difference hash, confirmed by eye
  • Re-scored the recorded weights on validation and test splits and on a de-duplicated test set
  • Bootstrap intervals for the rare class

Technologies

  • Python
  • YOLOv8
  • PyTorch
  • Model Evaluation
  • Reproducibility

Results

  • 4 of the 86 test images are exact or near copies of training or validation images; removing them lowers test mAP50 from 0.833 to 0.781
  • Rare class (mask worn incorrectly) is weak: recall 0.40 (95% bootstrap interval 0.09 to 0.80) on only 10 instances
  • The earlier quoted "85% accuracy" has no source in the notebook or training log

In progress: the audit and held-out re-evaluation are complete; retraining on a leakage-free split is not done yet. No model was retrained here.
