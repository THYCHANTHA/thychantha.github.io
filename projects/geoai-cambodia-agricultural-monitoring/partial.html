GeoAI: Satellite Agricultural Monitoring

A reproducible Sentinel-2 pipeline for land-cover and agricultural monitoring in Cambodia: cloud masking, vegetation indices and aligned ESA WorldCover labels.

Open full page View on GitHub

Problem

How can multispectral satellite imagery and machine learning support land-cover classification and agricultural monitoring in Cambodia, with spatially separated validation?

Overview

Research pilot (phase 3 of 6) on how multispectral imagery and machine learning can support land-cover classification in Cambodia, using only public data.

Methodology

  • Windowed reads from public Cloud-Optimized GeoTIFFs and a per-scene audit of the reflectance scaling
  • Cloud masking and a two-date dry-season composite
  • NDVI, EVI, NDWI and NDBI features
  • ESA WorldCover 2021 labels aligned to the windows; spatially separated windows

Technologies

  • Python
  • Sentinel-2
  • Geospatial
  • ESA WorldCover
  • Remote Sensing

Results

  • Three 3 km x 3 km windows in Kampong Cham Province (27 km2) yield 265,593 labelled pixels

In progress and resumable. WorldCover labels are reference (proxy) labels, not ground truth. No model has been trained yet and no accuracy figure exists.
