IoT Managing Parking System

In today's busy cities, managing parking efficiently is important to make the best use of space and improve convenience for users.

View PDF

Problem

Parking management can be inefficient when availability and access are handled manually. The goal was to automate sensing, access control, and local monitoring using an IoT prototype.

Overview

Arduino offers a flexible and affordable way to build customized smart parking solutions for busy cities. This prototype automates entry, detection, and monitoring using low-cost IoT components.

Methodology

  • RFID-based access control
  • Servo-controlled entry gate
  • Ultrasonic parking space detection
  • ESP8266 microcontroller workflow
  • Local monitoring dashboard via XAMPP

Technologies

  • ESP8266
  • RFID
  • Servo
  • Ultrasonics
  • XAMPP

Results

The prototype demonstrates how affordable embedded sensors and a local web stack can support smarter parking control and monitoring.
