ITC Student Management System (Backend)

A REST API backend (Node.js, Express, TypeScript, PostgreSQL) for students, courses, enrolments and grades with admin, lecturer and student roles.

Open full page View on GitHub

Problem

Student data, enrolment and marks need role-based access: admins manage records, lecturers input marks and students view their transcript.

Overview

Backend system for managing student data at the Institute of Technology of Cambodia, following an MVC architecture.

Methodology

  • MVC structure with Express and TypeScript
  • PostgreSQL schema: departments, users, students, courses, enrolments and marks
  • JWT authentication with bcrypt

Technologies

  • Node.js
  • Express
  • TypeScript
  • PostgreSQL
  • JWT

Results

The README lists the API endpoints as a roadmap, so treat it as a backend under development.
