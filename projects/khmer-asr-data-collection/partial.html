Khmer ASR Data Collection

Collected and openly shared Khmer speech recognition data, giving researchers and students access to high-quality linguistic resources.

Open full page View PDF

Problem

Khmer speech datasets are limited compared with major languages. The goal was to support local language AI research through better collection, processing, and annotation workflows.

Overview

This project focuses on collecting and preparing Automatic Speech Recognition (ASR) data for the Khmer language, enhancing linguistic resources by sharing the dataset openly for research and education.

Methodology

  • Khmer audio data collection
  • Web scraping for source material
  • Speech data organization and cleaning
  • Annotation preparation
  • Open dataset sharing for research

Technologies

  • Web Scraping
  • Data Collection
  • Machine Learning

Results

Delivered a structured, openly available Khmer speech dataset that supports future ASR research and model development.
