Assessing Khmer Language Understanding in LLMs

A comparative study of how efficiently XLM-RoBERTa and RoBERTa tokenise Khmer, how their embeddings relate Khmer words, plus a live tokenisation demo.

Open full page View on GitHub

Problem

How well do a multilingual model and an English-centric model support Khmer in tokenization efficiency and embedding quality, and can a simple vocabulary expansion start to close the gap?

Overview

Khmer is poorly covered by the vocabularies of many standard models. When a tokenizer has no Khmer tokens, text is split into many byte-level pieces, which wastes context length and can hide meaning. This project measures and visualises that effect.

Methodology

  • Vocabulary coverage and tokenization fertility for xlm-roberta-base and roberta-base
  • Embedding similarity for Khmer synonyms, Khmer-English translation pairs and random pairs
  • A corrected analysis using static (layer 0) and mean-pooled sentence embeddings
  • Vocabulary-expansion demo adding 15 Khmer tokens to roberta-base

Key features

  • FastAPI backend and single-page frontend to compare both models live
