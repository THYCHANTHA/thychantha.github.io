Khmer Large Language Model (LLMs)

Developed and deployed a Khmer LLM on Hugging Face, adapting transformer architectures and tokenization for Khmer text.

Open full page View on Hugging Face

Problem

Khmer is underrepresented in mainstream LLM tooling, limiting access to modern language technology. The goal was to build and publish a Khmer-focused language model for public use.

Overview

This project adapts transformer architectures and tokenization strategies for the Khmer language, resulting in a deployed language model on Hugging Face to improve Khmer NLP accessibility.

Methodology

  • Khmer-adapted tokenization
  • Transformer architecture fine-tuning
  • Transfer learning from base models
  • Public deployment on Hugging Face
  • Open access for Khmer NLP research

Technologies

  • Python
  • Hugging Face Transformers
  • NLP
  • Tokenization
  • Transfer Learning

Results

Published a working Khmer LLM on Hugging Face, improving accessibility and performance of Khmer language technology.
