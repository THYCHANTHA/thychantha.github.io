Khmer NLP Research: Stop-Words, TF-IDF and Retrieval

Reproducible experiments on Khmer stop-word strategies, TF-IDF representations and exploratory retrieval, with held-out queries, controls and uncertainty estimates.

Open full page View on GitHub

Problem

Khmer is written without word spaces and has very frequent function words. Does removing them help downstream tasks, which categories are safe to remove, and how far can a fixed list be trusted?

Overview

An independent research implementation informed by an earlier ITC university project on Khmer stop-word removal. It is not an authorised continuation of that project, and the original team's materials are not redistributed.

Methodology

  • Unicode normalisation and tokenisation (khmer-nltk, character-cluster baseline)
  • Dictionary import and validation with strategies A, B and C and protected categories
  • Statistical stop lists by document frequency
  • TF-IDF experiments and category-proxy retrieval evaluation

Technologies

  • Python
  • khmer-nltk
  • TF-IDF
  • Information Retrieval
  • Streamlit

Results

Research prototype v0.1.0. The question of which linguistic categories to remove is explicitly not answerable without a validated, categorised dictionary.
