Khmer Semantic Similarity Detection (RNN-based)

A two-stage transfer learning framework with a character-level autoencoder for Khmer semantic similarity, processing 14.8M characters.

Open full page View PDF View on GitHub

Problem

Khmer semantic similarity detection is difficult due to limited labeled datasets and complex morphology. The goal was to improve representation learning through transfer learning and a custom-built dataset.

Overview

This project built a two-stage transfer learning framework using a character-level autoencoder to detect semantic similarity between Khmer sentence pairs, curating a 1,200-pair dataset and processing 14.8M characters.

Methodology

  • Character-level autoencoder pretraining
  • Two-stage transfer learning framework
  • Curated 1,200-pair similarity dataset
  • Processed 14.8M characters
  • GRU-based sequence modeling

Technologies

  • Python
  • NLP
  • GRU
  • Transfer Learning
  • Autoencoder
  • Data Scraping

Results

Improved representation learning and prediction accuracy for Khmer semantic similarity through transfer learning.
