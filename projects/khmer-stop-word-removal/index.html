Natural Language Processing

Customized Khmer Stop-Word Removal System

A 511-word Khmer stop-word dictionary and text-cleaning pipeline, improving tokenization, feature quality, and ML model performance.

View PDF

Problem

Khmer lacks widely adopted stop-word resources, which hurts tokenization quality and downstream model performance. The goal was to build a reliable stop-word list and cleaning pipeline for Khmer text.

Overview

This project developed a custom 511-word Khmer stop-word dictionary paired with a text-cleaning pipeline, addressing the lack of standardized Khmer NLP preprocessing tools.

Methodology

  • 511-word curated Khmer stop-word dictionary
  • Text-cleaning and normalization pipeline
  • Tokenization quality improvements with Khmernltk
  • TF-IDF feature quality evaluation
  • Model performance comparison with Linear SVC

Technologies

  • Python
  • Khmernltk
  • TF-IDF
  • NLP
  • Linear SVC
  • Machine Learning

Results

Improved tokenization and feature quality for Khmer text, leading to measurable gains in downstream ML model performance.
