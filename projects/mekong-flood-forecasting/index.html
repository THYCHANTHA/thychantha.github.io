Mekong Discharge Forecasting

Forecasting daily Mekong discharge near Kratie 1 to 14 days ahead with honest baselines, ARIMA and gradient boosting, on model-simulated (GloFAS v4) data.

View on GitHub

Problem

How well can simple statistical and machine-learning models forecast a simulated daily Mekong discharge series, and how should the pipeline be organised so real gauge data can be substituted later?

Overview

A research prototype built so that authorised river-gauge observations can replace the simulated series later without rewriting the models. A dashboard always labels the data as simulated.

Methodology

  • GloFAS v4 reanalysis (1997 to 2025, 10,378 days) for one 5 km cell near Kratie
  • Persistence, seasonal-naive and climatology baselines
  • ARIMA on climatology-removed log discharge, and gradient boosting
  • Strict chronological train, validation and test periods (no leakage)

Technologies

  • Python
  • ARIMA
  • Gradient Boosting
  • Streamlit
  • Time-Series Forecasting

Results

  • Test period 2018-01-01 to 2025-05-31 (2,708 days): both models beat persistence at every horizon
  • MAE skill of 0.40 at 1 day for ARIMA and roughly 0.11 to 0.25 at 3 to 14 days for both models
  • No meaningful difference between ARIMA and gradient boosting beyond 1 day; errors concentrate in the July to October high-flow season

Scores are model-to-model agreement with GloFAS, not verification against real river flow. It makes no claim of real-world flood-forecasting accuracy and is not a flood warning system.
