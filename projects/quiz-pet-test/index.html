Quiz Pet Test

Helps grade 12 graduates prepare for medical entrance exams with structured quizzes for each course.

View Website

Problem

Students preparing for medical entrance exams need an accessible way to practice by subject. The goal was to build a simple, reliable web-based quiz platform for exam preparation.

Overview

Quiz Pet Test is a web application that helps grade 12 graduates prepare for medical entrance exams through structured quizzes for each course, building strong foundational skills through continuous practice.

Methodology

  • Course-based quiz structure
  • Interactive question practice
  • User accounts and progress tracking
  • Backend-driven content management
  • Responsive web interface

Technologies

  • PHP
  • HTML/CSS
  • JavaScript
  • SQL

Results

Delivered a practical exam-prep platform used by grade 12 graduates, demonstrating full-stack web development fundamentals.
