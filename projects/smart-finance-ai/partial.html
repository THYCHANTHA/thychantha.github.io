Problem

Finance teams often spend time manually reading invoices and entering data into spreadsheets. This project reduces repetitive work, improves consistency, and creates a cleaner data pipeline for reporting.

Overview

Smart Finance AI is an AI-assisted finance tool, founded by THY Chantha, for extracting invoice and receipt data from PDF or image files, validating records, checking confidence, detecting possible duplicates, and exporting clean data for reporting.

Methodology

  • Upload PDF/image documents
  • OCR text extraction
  • Invoice field detection
  • Confidence score
  • Duplicate checking
  • Excel/CSV export
  • Power BI-ready output

Technologies

  • Python
  • Streamlit
  • OCR
  • Tesseract
  • PDF Processing
  • Excel Export
  • CSV
  • Power BI

Results

The project creates a smarter finance data-entry workflow by combining OCR, validation, duplicate checks, export features, and dashboard preparation.
