Students Performance: Analysis and Grade Prediction

Exploratory analysis of exam scores for 1,000 students and a grade classifier, with the target leakage in the original notebooks called out.

Open full page View on GitHub

Problem

Describe how scores relate to gender, parental education, lunch type and test preparation, then predict the grade.

Overview

Two notebooks explore the public Students Performance in Exams dataset, derive pass/fail status and letter grades, and train classifiers.

Methodology

  • Distribution plots, outlier checks and mean comparisons
  • Derived total score, percentage, status and letter grade
  • Classification models

Technologies

  • Python
  • Pandas
  • Seaborn
  • Scikit-learn
  • Jupyter

Results

The near-perfect accuracy is target leakage (grade is computed from the same features), not evidence of predictive skill. The repository documents this limitation.
