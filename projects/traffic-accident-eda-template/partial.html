Traffic Accident EDA Template (Synthetic Data)

A short EDA notebook that generates 1,000 synthetic accident records labelled with four Cambodian cities, then cleans, summarises, plots and writes recommendations.

Open full page View on GitHub

Problem

Practise the steps of an EDA with pandas, NumPy, Matplotlib and seaborn, and show how severity, location and cause can be visualised.

Overview

A practice and template notebook for the exploratory-analysis workflow. The data are synthetic (numpy random, seed 42), so nothing in it describes real traffic in Cambodia.

Methodology

  • Generate data
  • Missing-value check and summary statistics
  • Count plots and a correlation heatmap with one-hot encoding
  • Conclusions and recommendations

Technologies

  • Python
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
