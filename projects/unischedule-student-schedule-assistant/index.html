UniSchedule: Student Schedule Assistant

A timetable assistant that imports schedule images with OCR (Tesseract.js) and sets class reminders, built with React 19, TypeScript and Vite.

View on GitHub

Problem

Typing a timetable in by hand is tedious and easy to forget.

Overview

Helps students manage their academic life: upload a physical or digital schedule image, extract the sessions, and get alarms before classes.

Methodology

  • OCR import of schedule images with Tesseract.js
  • Customisable reminder alarms with sound
  • Colour-coded categories (classes, self study, homework, assignments)
  • Dark mode and Framer Motion animations

Technologies

  • React
  • TypeScript
  • Vite
  • Tesseract.js
  • Framer Motion
