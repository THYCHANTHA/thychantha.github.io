WebinarLive: Webinar Landing Page

A responsive one-page landing page with a live countdown and validated registration form, built with React 19, TypeScript, Tailwind CSS 4 and Framer Motion.

Open full page View on GitHub

Problem

Show a polished, accessible and responsive landing-page build end to end.

Overview

A front-end design demo in a dark "Midnight Studio" style with scroll animations. The event, speakers and testimonials are fictional, and the form has no backend; the page says so on screen.

Methodology

  • DST-aware countdown using Intl
  • Form validation with loading and success states
  • Accessibility: aria-expanded on toggles, screen-reader text for ratings, descriptive alt text
  • Self-contained assets with no external CDN

Technologies

  • React 19
  • TypeScript
  • Tailwind CSS 4
  • Framer Motion
  • Vite
